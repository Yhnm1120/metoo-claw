# metoo-claw

AI Agent with Temporal Core + Self-Awareness Layer

Based on OpenClaw 2026.7.2, independent fork.

## Features

- **Temporal Core**: Session checkpoint, crash recovery, incremental compaction
- **Self-Awareness Layer**: Capability registry, causal chain, permission evaluator
- **17 modules total**: Agent knows who it is, what it can do, what it cannot do
